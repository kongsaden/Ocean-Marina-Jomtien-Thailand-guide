# Ocean Marina Jomtien – Local Guide (MVP)

## Included
- Responsive, mobile-friendly local guide
- English / Thai / Chinese language switch
- Search and category filters
- Place cards with Google Maps directions from Ocean Marina Jomtien
- Ocean Marina logo and aerial photograph supplied for this project

## Run locally
Open `index.html` in a modern web browser. Keep the `assets` folder beside it.

## Publish free with GitHub Pages
1. Create or sign in to a GitHub account.
2. Create a public repository, e.g. `ocean-marina-local-guide`.
3. Upload `index.html` and the complete `assets` folder.
4. In repository Settings > Pages, choose Deploy from a branch, select `main` and `/ (root)`, then Save.
5. Wait for GitHub Pages to publish the site. The public URL will look like `https://YOUR-USERNAME.github.io/ocean-marina-local-guide/`.
6. Create the final QR code only after confirming the published URL works on a phone.

## Important before public launch
- Verify every place name, branch, address, pin and current operating status.
- Google Maps directions links use place-name search destinations and ask Google Maps to calculate the live route. No fixed distance or travel time is claimed in this MVP.
- Replace any place that is not suitable or has changed.
- This is a standalone website, not a WhatsApp chatbot. It can be opened from a WhatsApp message or QR code.
- No API key, paid hosting, database or WhatsApp API is required for this MVP.
